# /data

Input data for every notebook in the repository. Nothing in this folder is generated by the code except `cvat_original_frames/`.

## Contents

| Path | Description |
|---|---|
| `cvat_annotations/` | Unzipped CVAT export of the expert-assisted annotations ("Segmentation mask 1.1" format). |
| `bluerov_videos/` | Placeholder for the BlueROV2 and DJI videos. See below. |
| `cvat_original_frames/` | Created by `utils/extract_cvat_frames.py`: the 11 annotated frames saved as 1920x1080 PNG. |

## Videos

Video files are not committed so default filenames are included in .gitignore. A shared link to the files used in this project can be found [here](https://1drv.ms/f/c/3f3ac98f81835410/IgAfbXGVdm4FS7mlVGc1KUOOAXZNMT1ZssA3eaIyHXDSUDk?e=IsQwRs).

The notebooks expect the following filenames inside `data/bluerov_videos/`:

| Filename | Description |
|---|---|
| `Myora-BlueROV.mp4` | About 10 minutes of 1080p footage from the onboard BlueROV2 camera at Myora Bay, Moreton Bay. |
| `Shortened.mp4` | A shortened clip used for quick enhancement runs. Any short clip with this name works. |
| `Myora-DJI-4K.mp4` | Placeholder name for the 4K DJI Osmo Action 5 Pro footage collected at Myora Reef on 15 October. The filename is set in the notebook's configuration cell and can be changed freely. |

## CVAT annotations

`coral_eval.ipynb` reads the export from `data/cvat_annotations/`. The export must contain:

- `JPEGImages/` (or `images/`) with the annotated frames, named like `frame_000946`
- `SegmentationClass/` with one colour-coded PNG mask per frame
- `labelmap.txt` listing each CVAT label and its colour

The annotated frames are 11 frames from the Myora-BlueROV.mp4 footage (frame numbers 946, 2035, 2276, 2421, 3076, 3799, 4284, 4644, 5782, 8478 and 9529).
